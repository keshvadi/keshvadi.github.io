How to Create Your Webpage on EC2

1. Download the key
wget http://keshvadi.github.io/dl/sina.pem
2. Set permission
chmod 400 sina.pem
3. Connect to your EC2
ssh -i "sina.pem" ec2-user@18.216.143.39
4. Go to website folder
cd /var/www/html
5. Create your file
sudo nano YOUR-NAME.html
6. Write anything you want, then save and exit
Write your content in the editor.
Press: Ctrl + X → then press Y → then Enter
7. Open in browser
Go to this address:

http://18.216.143.39/YOUR-NAME.html

Note: Replace YOUR-NAME.html with the actual name you choose (example: sina.html or test.html)
